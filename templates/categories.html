Why these scores read differently

Bots don't count as life Dependabot and renovate commits are filtered before scoring. A repo kept alive by dependency bumps still looks like what it is.
Time decays, honestly Absolute curves, not rank games: a repo silent for eight months scores the way it feels to depend on it.
Every number is auditable Each project page shows the raw signals and the math that turned them into a score. No vibes, no star worship.

How it works

1 · Collect nightly Repo signals are pulled from the GitHub API and cached: commits, releases, issue and PR close times, contributors, CI, tests.
2 · Score within category Signals are weighted and normalized inside each ecosystem, so a plugin is measured against its own scene, not against a framework.
3 · Publish static Every run renders plain HTML — no login, no tracking, no JS required. Scores stay comparable within a category, never across.
